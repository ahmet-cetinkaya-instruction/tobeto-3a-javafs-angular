# Tobeto 3.A - Fullstack - Frontend Angular Training

This repository is a snapshot created for documentation and knowledge-sharing purposes, capturing the content of a technical training delivered for a specific audience. The training focused on building modern web applications using Angular as the frontend framework, integrated with a backend API.

## Main Covered Topics

- **Frontend Development with Angular**: Core concepts, component-based architecture, and routing.
- **API Integration**: Consuming RESTful APIs using OpenAPI generated services for seamless backend communication.
- **UI Development**: Implementing responsive user interfaces with Bootstrap.
- **Practical Application**: Developing a "Rent a Car" application, including features for managing brands and models.
- **Technologies Used**: Angular, TypeScript, Bootstrap, OpenAPI Generator.

> Note: This repository is not intended for ongoing development; it is an archive of a specific training program and is provided for reference and knowledge sharing.
